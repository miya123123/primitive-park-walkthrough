# Primitive Park Walkthrough

> **Status**: Accepted for vertical slice
> **Author**: User + Claude Code Game Studios
> **Last Updated**: 2026-08-27

## Overview

「Primitive Park」は、色鮮やかなプリミティブ形状だけで作られた72m四方の遊園地を、来園者モデルを眺めながら三人称視点で自由に歩き回るPC向けウォークスルーゲームです。プレイヤーは入口から園内へ入り、観覧車・ジェットコースター・メリーゴーラウンド・フリーフォール・ゴーカートを体験し、案内板を読みながら短時間で園内を巡ります。

## Player Fantasy

自分で作られた小さな遊園地を歩き、遠くから見える目印へ近づき、動く乗り物を眺める楽しさを提供します。操作は軽快で、失敗や戦闘のプレッシャーを持たせず、形・色・距離感を楽しめる体験を目指します。

## Core Loop

1. 入口から園内へ入る。
2. 中央広場と道を使って3施設を見つける。
3. 各施設の案内板と自動演出を眺め、乗り場でEを押す。
4. 次の到着を待って1周乗車し、降車後に好きな順番で園内を巡る。

## Required for MVP

- PCで起動できるGodotゲーム
- WASD移動、マウス視点、ジャンプ、ダッシュ
- 地面・柵・施設の衝突
- プリミティブだけで構成された3施設
- 施設の自動演出と案内板
- 観覧車・ジェットコースター・メリーゴーラウンドへの1周乗車
- 最小HUDと現在位置表示

## Out of Scope

戦闘、NPC、クエスト、スコア、セーブ、ネットワーク、乗り物の操縦、ミニゲーム、外部3Dモデル、画像テクスチャ、音源、Web最適化。

## Success Criteria

プレイヤーが起動後30秒以内に操作を理解し、2分以内に3施設すべてへ徒歩で到達でき、各施設でEを押して次回到着後の1周乗車と自動降車を体験でき、どの視点からでも園外へ落下せず、3施設がプリミティブ形状であることを視覚的に確認できること。
