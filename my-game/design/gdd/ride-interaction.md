# 乗り物インタラクション

## Overview

Primitive Parkの観覧車、ジェットコースター、メリーゴーラウンドを、来園者が自分で乗って1周体験できるようにする。プレイヤーは乗り場でEを押し、動いている車両が次に乗り場へ到着するまで待つ。到着したら着座して1サイクルだけ運行し、乗り場近くの安全な地点へ自動で降車する。運行中も三人称カメラで周囲を見回せる。

## Player Fantasy

歩いて見つけた施設を遠くから眺めるだけでなく、実際に座席へ乗り込み、観覧車の高さ、コースターの速度、メリーゴーラウンドの回転を来園者モデルごと体験する。待機と自動降車を明確にして、短時間の散策でも操作に迷わない。

## Detailed Rules

- 乗り場の判定エリアへ入り、地上付近でEを押すと、その施設の次回到着を予約する。
- 予約中にエリアを離れると予約をキャンセルし、施設は通常の自動演出へ戻る。
- 乗り物が乗り場へ到着すると、プレイヤーを専用座席アンカーへ移し、衝突を一時無効化して着座姿勢を表示する。
- 乗車中はWASD、ジャンプ、ダッシュを無効化する。マウス視点、Escによるマウス解放は維持する。
- 観覧車は車輪1回転、メリーゴーラウンドは回転1周、コースターは閉ルート1周を完了条件とする。
- 1周完了時に安全な降車マーカーへ配置し、衝突と通常の歩行姿勢を復元する。
- 1人用のため、別の施設へ同時に予約・乗車することはできない。

## Formulas

- `phase_next = fmod(phase + max(delta, 0) × max(speed, 0), period)`。`phase`は角度またはルート距離、`speed`は毎秒の進行量、`period`は`2π`または閉ルート長で、いずれも`phase ∈ [0, period)`とする。
- 通常フレームは`station_crossed = phase_next < phase`、大きな時間刻みは`delta × speed >= period - phase`で判定する。正方向に位相の周期境界をまたいだときに乗り場到着または1周完了とし、複数周をまたぐ場合も1回だけイベントを発行する。
- 例: 観覧車の`speed=0.22rad/s`では`2π / 0.22 ≈ 28.6s`で1回転、カルーセルの`0.45rad/s`では`≈14.0s`で1周する。
- コースターは隣接するルート点の距離を合計した`period`を使い、`phase / period`が0から1へ進む間に車両位置を線形補間する。

## Edge Cases

- 速度、周期、乗車判定半径、乗り場許容値が0以下、または座席・降車マーカーが欠落する設定は起動時に拒否する。
- 乗車予約中にプレイヤーがジャンプや落下を始めた場合、乗り場へ戻るまで予約を成立させない。エリアを離れた場合はキャンセルする。
- 乗車中に座席ノードが無効になった場合は、現在地または有効な降車マーカーへ復帰し、歩行と衝突を復元する。
- ルートの1ステップが周期を複数回またぐ場合でも、運行時間は1周として扱い、次フレームから通常演出へ戻す。
- 同じフレームに複数の乗り場イベントが来た場合は、先に保持した単一の乗車予約だけを処理する。

## Dependencies

- Park Configuration: 各施設の乗り場、降車地点、速度、判定値を提供する。
- Park Layout / Attraction Motion: 座席アンカー、移動ノード、閉ルートを生成・更新する。
- Third-Person Movement: 乗車中の入力停止と降車後の移動復元を受け持つ。
- Minimal HUD / Landmark Guidance: 乗車可能、到着待ち、運行中の状態をイベントで表示する。

## Tuning Knobs

- `boarding_radius`（1.5〜3.0m）: 乗り場でEを受け付ける範囲。
- `station_tolerance`（0.1〜0.5radまたはm）: 乗り場到着とみなす位相境界の許容値。
- `rotation_speed` / `cart_speed`（現行値の0.5〜2.0倍）: 通常演出と1周の所要時間。
- `boarding_position` / `exit_position`: パッド、座席、固定構造物と干渉しない地上位置。
- `ride_arm_pose_degrees` / `ride_leg_pose_degrees`: 三人称で着座が読み取れる手足の姿勢。

## Acceptance Criteria

- 3施設それぞれで、乗り場へ入りEを押すと、次回到着を待って着座する。
- 観覧車1回転、コースター1周、メリーゴーラウンド1回転の後、プレイヤーが安全地点へ自動降車する。
- 乗車中はプレイヤーが車両座席へ追従し、WASD移動とジャンプが発生せず、マウスで三人称視点を旋回できる。
- 予約キャンセル、座席無効化、複数乗車要求の各ケースでプレイヤーが歩行可能な状態へ戻る。
- 通常・クリーンコピーの自動テストと実画面QAで、HUD表示、着座姿勢、1周完了、自動降車を確認できる。
