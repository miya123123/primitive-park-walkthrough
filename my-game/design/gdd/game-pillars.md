# Game Pillars

## 1. 形で伝わる遊園地

Box、Cylinder、Sphere、Capsuleなどの単純形状と色の組み合わせだけで、遠景からでも施設の用途が伝わるシルエットを作る。

## 2. 自由に歩いて見つける

一本道で誘導せず、中央広場から3施設へ複数の歩行ルートを用意する。柵と道は迷子防止のために使い、探索を止めるためには使わない。

## 3. 動きが景観と体験を生む

観覧車、メリーゴーラウンド、コースター車両をゆっくり動かし、操作しなくても園内に生命感を持たせる。乗車時は次の到着を待ち、1周だけ乗って安全に降りられる。演出はプレイヤーを不意に拘束しない。

## 4. すぐ触れて、すぐ理解できる

起動直後に操作説明を表示し、乗り場へ近づくとEキーの案内、待機中は到着待ち、乗車中は1周運行中の状態を表示する。HUDは景観を覆わない最小構成にし、すべての主要情報は形・文字・位置の組み合わせで伝える。
