# Primitive Park Smoke QA — 2026-08-30

## Scope

乗車時にプレイヤーの見た目が座席から浮く問題と、ゴーカートのコース点が潰れて乗車直後に終了する問題を修正した。通常コピー、Git archive から作成したクリーンコピー、GoPeak Runtime の実入力・実画面を確認した。

## Automated Checks


確認内容:

- `ride_seat_pivot_height=0.84` を設定から読み込み、プレイヤーの物理ルートを座席アンカーへ追従させたまま、見た目だけを座面へ下げること。
- 観覧車、ジェットコースター、メリーゴーラウンド、フリーフォールの着座姿勢で腰位置がアンカーへ揃い、降車時に表示オフセットと衝突が復元されること。
- ゴーカートの `Vector3` コース点を保持し、JSON配列入力との互換性も維持すること。
- ゴーカートがカウントダウンから `racing` へ進み、明示入力で開始位置から移動し、Eで退出できること。
- 既存のプリミティブ許可リスト、HUD、カメラ、記録保存を含む既存回帰を維持すること。

## GoPeak Runtime / Visual Checks

- GoPeak `v2.3.9` の MCP stdio サーバーで `tool-catalog` から `runtime` / `testing` を有効化した。
- Runtime addon を一時クリーンコピーだけに Autoload し、対象リポジトリのプリミティブ専用方針を変更せずに検証した。
- Godot 4.6.2、Metal / OpenGL Compatibility、1280×720の実ウィンドウで実施した。
- ゴーカート乗り場（ワールド座標 `[8, 0, 20]`）へ実行時プロパティで移動し、GoPeak `inject-key` の E で乗車した。
- GoPeak `inject-action` の `move_forward` を4.3秒入力し、`status=racing`、`time_seconds=1.9667`、カート位置 `(-10.1768, 0.45, 5.2327)` を取得した。開始位置 `(-10, 0.45, 6)` から移動しており、即時終了していない。
- E退出後に `is_riding=false`、フリーフォール乗車後に `is_riding=true`・`harness` を取得した。
- フリーフォール乗車中の `VisualRoot` は `O=(0, -0.84, 0)`、降車後は `O=(0, 0, 0)` となることを Runtime tree で確認した。
