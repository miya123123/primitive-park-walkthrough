# Primitive Park スモークテスト

実施日: 2026-08-25
対象: `my-game` / Godot 4.6.2 / macOS Apple M2 / Forward+ / Jolt Physics3D

## 実行コマンド

```bash
godot --headless --verbose --path my-game \
  --script tests/run_all_tests.gd \
  --log-file /private/tmp/primitive_park_tests_final.log
```

## 結果

- 終了コード: `0`
- 結果: `ALL TESTS PASSED (126 assertions)`
- ログ確認: `ERROR`、`SCRIPT ERROR`、`WARNING`、`Parse Error`、`Invalid`、`leaked` の該当行なし
- 構成検証: 48mワールド、3施設、必須キー、異常なワールドサイズの拒否を確認
- 移動検証: 斜め移動の速度正規化、重力、接地ジャンプ、視点ピッチ制限を確認
- シーン検証: 施設ノード、3つのArea3D、プリミティブ形状、プレイヤーのCapsuleShape3Dを確認
- 統合検証: W入力で実際にカルーセルへ進み、`landmark_entered`イベントが`Carousel`を通知することを確認
- 演出検証: カルーセル回転とジェットコースターカートの経路移動を確認

## 実ウィンドウ確認

Godotエディターからメインシーンを起動し、昼色の空、芝生、メイン通路、中央カルーセル、観覧車、ジェットコースター、左上操作HUD、中央クロスヘアを確認した。W入力でカルーセルへ接近し、接近前後で画面内の施設サイズが変化した。確認後はデバッグウィンドウを閉じ、プレイを停止した。
