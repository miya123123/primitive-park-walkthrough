## 2. 原因確認と方針

`project.godot` の `environment/defaults/default_clear_color` は、実行時に `src/main.gd` が生成する `WorldEnvironment` のプロシージャルスカイで置き換わります。画面全体の印象を決めているのは、同ファイルの `_configure_environment()` にある環境光と太陽光です。

照明色や影のコントラストを個別に変えると遊具ごとの見え方が変わるため、昼光環境の最終輝度だけを約10%下げる方針にしました。これにより、既存の環境光 `0.75`、太陽光 `1.2`、色設定、影設定を保ったまま、3Dシーンの白飛びを抑えられます。

## 3. 実装詳細

[my-game/src/main.gd](/Users/miya/program/app/Koji/2_遊園地/my-game/src/main.gd:69) の `Environment` に以下を追加しました。

```gdscript
environment.adjustment_enabled = true
environment.adjustment_brightness = 0.9
```

### 4.2 実画面確認

- [調整前画像](./画面輝度調整前_20260901125440.png)
- [調整後画像](./画面輝度調整後_20260901125440.png)

画像サイズは両方とも1280×720です。RGBから算出したシーン領域（Y=160以降）の平均輝度は `219.32` から `198.31` へ下がり、約9.6%の低下でした。RGB輝度250以上の画素割合は `15.07%` から `0.00%` になりました。調整後も空、遊具、来園者、影を確認でき、HUDは暗いパネル上で従来どおり読めます。

実画面起動ログはApple M2のOpenGL Compatibilityレンダラーを使用しました。終了時の `ObjectDB instances leaked` はキャプチャ補助スクリプトの終了処理で出る既知の警告であり、ゲームテストの合否とは分離しています。
