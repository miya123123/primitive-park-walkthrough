# 詳細報告：フリーフォールタワーとゴーカート追加

## 1. 依頼内容

「以下のフリーフォールタワーとゴーカートを乗り物として追加してください。フリーフォールタワー：一気に落下するあのドキドキ感は、3Dゲームでこそ再現する価値があります。落下前の「間」の演出にこだわりますと、プレイヤー様の心を掴んで離しませんよ。 ゴーカート：ご自身で運転できる乗り物はゲーム性がぐっと高まります。園内にレースコースを作りますと、乗り物でありながらミニゲームとしても長く楽しんでいただけます。」

## 2. 変更した主なファイル

### 実装

- `assets/data/park_config.json`: 72mワールド、スポーン位置、2施設の配置と全チューニング値、10点コース、4チェックポイント、3周設定を追加。
- `src/core/park_config.gd`: 5施設、スポーン、フリーフォール範囲、コース点・チェックポイントの検証を追加。
- `src/core/kart_math.gd`: 速度接近、速度依存ステアリング、タイム表示、進行方向判定を追加。
- `src/core/kart_record_store.gd`: ConfigFileによるベストタイムの安全な読み書きを追加。
- `src/gameplay/ride_provider.gd`: `station_ready`、`cycle_completed`、`progress_changed`と共通メソッドの契約を追加。
- `src/gameplay/free_fall_controller.gd`: ハーネス、上昇、ランダムサスペンス、落下、制動、着地の状態機械を追加。
- `src/gameplay/go_kart_controller.gd`: CharacterBody3D車体、アーケード物理、衝突減衰、順序付き周回判定、カウントダウン、結果、記録保存を追加。
- `src/gameplay/park_builder.gd`: 塔、車体、S字を含む閉ループコース、固定バリア、チェックポイントゲート、乗り場をプリミティブから生成。
- `src/gameplay/attraction_animator.gd`: 自動3施設を共通プロバイダ契約へ接続。
- `src/gameplay/ride_coordinator.gd`: 施設ごとのプロバイダ登録、E途中退出、Rリセット、進捗信号の中継を追加。
- `src/gameplay/player_controller.gd`: プレイヤーグループ、E退出、Rリセットのイベントを追加。
- `src/main.gd` / `scenes/Main.tscn`: 設定スポーン、5施設登録、ゴーカートブレーキ入力を追加。
- `src/ui/park_hud.gd` / `assets/i18n/ui.csv`: 安全領域対応のゴーカート進捗パネル、フリーフォール段階表示、操作説明を追加。

- `docs/architecture/control-manifest.md`、`docs/registry/architecture.yaml`、`docs/architecture/tr-registry.yaml`: 72m制約、プロバイダ、進捗状態、TR-ride-005〜008を登録。

- `production/qa/smoke-2026-08-28.md`、`production/qa/evidence/ride-expansion-playtest.md`: 自動・実画面QA手順と結果。
- `tests/helpers/test_suite.gd`: 設定、計算、既存3施設、フリーフォール、ゴーカート、HUD、記録保存を326アサーションで検証。
- `tests/gui_capture.gd`: 通常レンダリングの初期・カート・フリーフォール画像を決定的に取得。

## 3. 仕様上の判断

- フリーフォールの待機時間は毎回2.5〜4.5秒から抽選し、テスト時だけ乱数シードを注入できます。
- ゴーカートは対戦相手やドリフトを追加せず、操作の気持ちよさと自己ベスト更新に集中する3周構成としました。
- コース外へ抜けてもチェックポイントはスキップできず、逆走では周回が進みません。
- ゴーカートのみE途中退出とRリセットに対応し、フリーフォールと既存の自動運行は完走後に安全降車します。
- 既存のプリミティブ専用方針を維持し、BoxMesh、CylinderMesh、SphereMesh、CapsuleMeshだけを使用しています。

### 実画面

- Godot通常アプリをMetal / Forward+、1280×720で起動。
- 初期画面で72m園内と5施設のシルエット、操作説明を確認。
- ゴーカート着座後の`GET READY — 3`、W/S/A/D・Shift・R・Eの操作説明、車体視点を確認。
- フリーフォール上昇後の`FREE FALL — HOLD ON...`、塔上部の車体位置、点滅ランプを確認。
- 実画面キャプチャ終了後、ゲームプロセスを停止。

キャプチャ用SceneTree終了時にはGodotのObjectDB cleanup警告が1件残りますが、通常のゲームロジックとヘッドレス統合テストのログにはエラー・警告がありません。画像は保存済みで、警告はQA補助スクリプトの終了処理に限定されます。
