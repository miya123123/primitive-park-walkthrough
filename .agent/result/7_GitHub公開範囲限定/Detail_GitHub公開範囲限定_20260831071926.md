# 詳細報告: GitHub公開範囲限定

## 1. ユーザー依頼

初回依頼:

`$github 本ゲームをGitHubに公開してください。GitHub Pagesから本ゲームのデモをプレイできるようにしてください。`

公開範囲の追加指定:

`デプロイするのはソースコードとREADMEのみとしてください。`

## 2. 公開対象の整理

ルートGitには、ゲーム本体以外に `.agent`、`Post`、CCGS内部設定、設計資料、QA記録、結果報告書などが含まれています。追加指定に従い、それらをpush対象から除外しました。

一時公開ツリーの構成は次のとおりです。

```text
README.md
.github/workflows/deploy-pages.yml
my-game/project.godot
my-game/export_presets.cfg
my-game/scenes/*.tscn
my-game/src/**/*.gd
my-game/src/**/*.gd.uid
my-game/assets/data/park_config.json
my-game/assets/i18n/ui.csv
my-game/assets/i18n/ui.csv.import
my-game/assets/i18n/ui.en.translation
my-game/tests/**/*.gd
my-game/tests/**/*.gd.uid
```

READMEは公開用にゲーム概要・操作方法・ローカル起動・テスト・公開構成だけを記載したものを用意しました。
