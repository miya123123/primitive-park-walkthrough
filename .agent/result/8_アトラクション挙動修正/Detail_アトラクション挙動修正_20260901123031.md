## 2. 原因と修正方針

### 2.1 ローラーコースターの視点変更

従来の`PlayerController._sync_to_ride_anchor()`は、乗車中の毎フレームで次を実行していました。

```gdscript
global_position = _ride_anchor.global_position
rotation.y = _ride_anchor.global_rotation.y
```

ローラーコースターの座席アンカーは車両の進行方向に合わせて回転するため、支柱付近の区間切り替えでプレイヤー本体、`CameraYaw`、`CameraPitch`、`SpringArm3D`へ回転が伝播していました。

修正後は`_ride_id == &"roller_coaster"`のときだけプレイヤー本体のY回転追従を止めます。位置は座席アンカーへ追従するため着座状態は維持され、`apply_camera_motion()`による手動の視点操作はそのまま利用できます。フェリスホイール、メリーゴーラウンド、フリーフォール、ゴーカートの回転・姿勢契約は変更していません。

### 2.2 ゴーカートの壁による閉塞

従来は各区間の接線から左右の法線を計算し、区間ごとに独立したレール端点を生成していました。急カーブでは隣接区間の端点が同じ頂点で共有されず、レールが走行レーン側へ交差する場合がありました。

修正後は`KartMath.closed_track_boundaries()`で各頂点の入射接線・出射接線を合成したマイター頂点を一度だけ計算し、同じ頂点列を隣接区間へ共有します。極端に鋭い角は半幅の2倍以内へ制限して、長い突起が新たな障害物にならないようにしています。コースの元の10点、レーン幅3.6m、チェックポイント順、3周設定は維持しています。

### 2.3 アトラクション名の向き

`ParkBuilder._create_sign()`で生成するアトラクション名の`Label3D`を`BaseMaterial3D.BILLBOARD_DISABLED`へ変更しました。これにより、カメラの方向へ毎フレーム正面化せず、看板ボードのローカル向きに固定されます。入口案内ラベルなど、アトラクション名ではない表示の既存設定は変更していません。
