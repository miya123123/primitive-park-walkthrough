# アトラクション挙動修正

## 結果

ご指定いただいた3点を実装し、Godotの自動テストとGoPeakの実入力テストまで完了しました。コースターは支柱通過時もカメラの向きを維持し、ゴーカートは壁に塞がれず3周を完走できる状態になっています。アトラクション名の看板文字はビルボード回転を無効化し、ボードに固定されるようにしました。

## 依頼内容

対象コンテキスト: `.agent/Context/6_Mod/6_Context.md`

依頼された修正:

1. RollerCoaster乗車中、柱に到達するタイミングで毎回変更されるカメラ視点を変更されないようにする。
2. ゴーカートの途中を塞いでいる壁を修正し、ゴールできるコースにする。
3. アトラクション名のボード上テキストをカメラ正面へ回転させず、固定表示にする。
4. GoPeakを使用してテストする。

実装指示: 「では、実装してください。」

## 実施内容

- `PlayerController`でローラーコースター乗車時だけプレイヤー本体の向きを座席アンカーへ追従させず、カメラ親のワールド向きを固定しました。乗車中のマウスによる手動カメラ操作は維持しています。
- `KartMath.closed_track_boundaries()`を追加し、前後区間で共有するマイター頂点から左右の連続したレール境界を生成するようにしました。急カーブで独立した区間端が交差して走行路を塞ぐ問題を解消しています。
- `ParkBuilder`のゴーカート境界生成を新しい連続レールへ切り替えました。設定ファイルのコース点、幅、3周ルールは変更していません。
- アトラクション名の`Label3D.billboard`を`BILLBOARD_DISABLED`へ変更しました。
- 上記3点の回帰アサーションをテストスイートへ追加しました。
