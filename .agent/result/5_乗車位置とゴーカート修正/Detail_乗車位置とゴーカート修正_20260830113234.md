# 詳細報告：乗車位置とゴーカート修正

## 1. 依頼と受入条件

依頼元は `/Users/miya/program/app/Koji/2_遊園地/.agent/Context/5/5_Context.md` です。内容は「乗り物乗車時にプレイヤーが浮く」「ゴーカート乗車後に移動できず終了する」という不具合の修正と、GoPeak MCPを使った実装・テストでした。

受入条件を次のように具体化しました。

1. 乗車中も物理プレイヤーのルートは座席アンカーへ一致する。
2. 表示モデルの腰が座席アンカーへ一致し、降車すると立ち姿勢へ戻る。
3. ゴーカートのコース点が生成時の `Vector3` のまま保持される。
4. Eでゴーカートへ乗車し、W入力後も `racing` を維持して開始点から移動する。
5. Eでゴーカートを退出でき、既存の自動運行・フリーフォールへ影響しない。
6. 通常コピーとキャッシュなしクリーンコピーの両方で回帰テストが成功する。

## 2. 修正前の再現と原因

### 2.1 プレイヤーの浮き

`Player` のルート原点はカメラ・衝突・入力を担い、`VisualRoot` 配下の足ピボットは立ち姿勢でY=0.84付近にあります。従来は `Player.global_position` を座席アンカーへ合わせるだけだったため、腰より下にある座面へルート原点が置かれ、表示モデルが約0.84m上へ浮いて見えていました。

### 2.2 ゴーカートが即時終了

生成側 `park_builder.gd` はコース点を `Vector3` として構築します。一方、`go_kart_controller.gd` は全要素を配列として再変換していたため、`Vector3` を `ParkConfig.vector3_from_array()` に渡した場合のフォールバック `Vector3.ZERO` が全点へ適用されていました。全チェックポイントが同一点となり、E乗車後のW入力を待たずに周回完了扱いへ進んでいました。

修正前の実行時プローブでは、E乗車後の状態が `riding=true` でも、W入力後に `state=finished`、移動距離約0.2667m、経過0.25秒という再現結果でした。

## 3. 実装内容

### 3.1 座席ピボットの設定化

- `assets/data/park_config.json` に `player.ride_seat_pivot_height=0.84` を追加。
- `src/core/park_config.gd` の正値検証へ追加。
- `src/gameplay/player_visual.gd` が立ち姿勢位置を保存し、乗車中は `Vector3.DOWN * 0.84` を表示ルートへ適用。
- 乗車開始時に表示ヨーを0へ戻し、降車時に立ち姿勢位置を復元。

この構造により、`Player` の物理ルートと座席アンカーの一致を保ったまま、見た目の腰・足だけを正しい高さへ配置できます。衝突形状は従来どおり乗車中に無効化され、降車時に復元されます。

### 3.2 コース点の型保持

`go_kart_controller.gd` の設定ループで、要素が `Vector3` の場合は各成分をコピーし、配列の場合だけ `vector3_from_array()` を呼ぶようにしました。生成シーンの型付き値と、将来のJSON配列値の双方を受け付けます。

### 3.3 回帰テスト

`tests/helpers/test_suite.gd` に次を追加・強化しました。

- 設定値 `ride_seat_pivot_height` の検証。
- 既存3施設とフリーフォールで、ルートと腰のアンカー距離、表示オフセットを検証。
- 自動降車後の表示オフセットと衝突復元を検証。
- ゴーカートの開始点と設定点の一致を検証。
- カウントダウン完了後に30フレームのスロットルを進め、移動距離が0.5mを超え、状態が `racing` のままであることを検証。
- E退出後に表示オフセットが0へ戻ることを検証。

## 5. 変更範囲と判断

- Runtime addonは対象リポジトリへ追加していません。プリミティブ専用プロジェクトの構成を維持し、GoPeak Runtime検証時だけ一時コピーへ同梱しました。
- 物理ルートを下げる設計にはせず、表示ルートだけを設定値分だけ下げました。これによりカメラ、Area3D、衝突、RideCoordinatorの既存契約を変更せずに浮きを直せます。
- コース点は型を壊さずに扱い、JSON由来の配列にも対応する最小修正としました。
- AI対戦、ドリフト、コース設計変更、外部アセット、音声は今回の範囲外です。
