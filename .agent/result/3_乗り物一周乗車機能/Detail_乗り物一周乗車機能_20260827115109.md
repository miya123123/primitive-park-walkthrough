# 乗り物一周乗車機能 詳細報告

## 1. 依頼内容

ユーザーから「各種乗り物に乗れる機能を実装して下さい。」と依頼され、その後「Implement the plan.」「実装してください。」の指示を受けた。対象は既存のGodot製Primitive Parkで、対象施設は観覧車、ジェットコースター、メリーゴーラウンドの3施設、操作フローは乗り場でE入力、次の到着を待機、1周運行、自動降車とした。

## 2. 実装内容

### 乗車状態と位相

- `src/core/ride_math.gd`に、周期位相の正規化、駅到着判定、閉ルート接線計算を追加。
- 複数周期をまたぐ大きな時間刻みも検知する`crossed_station_by_delta`を追加。
- `src/gameplay/attraction_animator.gd`を施設ごとの`decorative`、`waiting`、`boarding`、`riding`状態を持つ実装へ拡張。
- 観覧車は車輪角度、メリーゴーラウンドは回転角、コースターは閉ルート距離を位相として扱い、1周イベントで`cycle_completed`を発行。

### プレイヤーと調整役

- `src/gameplay/ride_coordinator.gd`を新設し、単一プレイヤーの乗車予約を管理。
- `Area3D.body_entered/body_exited`で乗り場の入退場を検出し、`interact_requested`、`station_ready`、`cycle_completed`を接続。
- 予約中に乗り場を離れた場合はキャンセルし、座席が無効化された場合も乗車を中断して歩行状態へ戻す。
- `player_controller.gd`にE入力、座席追従、衝突の遅延無効化・復元、乗車中の入力ロックを追加。
- `player_visual.gd`にJSON設定の着座姿勢ブレンドを追加。

### 施設生成とHUD

- `park_builder.gd`で3施設に座席アンカー、乗り場パッド、乗り場Area3D、降車`Marker3D`を生成。
- `main.gd`で`RideCoordinator`を生成し、3施設の記述子を登録。
- `park_hud.gd`に、乗車可能・到着待ち・乗車中のイベント駆動バナーを追加。
- `assets/i18n/ui.csv`へ`E RIDE`、待機、運行中の表示文言を追加。

### 設定・設計資料

- `assets/data/park_config.json`へ乗り場位置、降車位置、判定半径、駅許容値、着座姿勢、地上判定値を追加。
- `park_config.gd`で新しい数値、位置、速度、判定値を起動時検証。
- 乗車GDD、ADR-0003、TRレジストリ、アーキテクチャレジストリ、EPIC/Storyを追加・更新。
