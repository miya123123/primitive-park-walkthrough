# Primitive Park Walkthrough — README_v2

> 🎡 **Box・Cylinder・Sphere・Capsuleだけで作られた、手作り感あふれる3D遊園地を自由にお散歩できるゲームです！**
> 本ドキュメントは既存READMEを一切見ずに、ソースコード・シーン・設定ファイルから fresh に書き起こした v2 版です。

## 1. ゲーム概要

| 項目 | 内容 |
| ---- | ---- |
| タイトル | **Primitive Park Walkthrough（プリミティブ・パーク・ウォークスルー）** |
| ジャンル | 3D遊園地ウォークスルー／探索＋乗車体験 |
| 視点 | 三人称視点（背面追従＋マウスオービット） |
| エンジン | Godot 4.6系（GDScript / JoltPhysics3D / gl_compatibility） |
| 解像度 | 1280x720、空色クリアの昼の遊園地 |
| プレイ人数 | 1人（PCキーボード＋マウス推奨） |
| 開発枠 | Claude Code Game Studios ＋ データ駆動プロシージャル生成 |

**あなたは赤い帽子をかぶった来園者です。**
南門の `PRIMITIVE PARK` の看板をくぐったら、72m四方のカラフルな遊園地が目の前に広がります。
中央広場から十字のメインストリートが伸び、その先に5つの大型アトラクションがそびえ立ちます。

目的はとてもシンプルです：

1. 園内を自由に歩いてお目当てのアトラクションを見つける
2. 乗り場の黄色いパッドに立って `Eキー` で乗車する
3. 次の到着を待って1周乗車し、景色を楽しんで自動降車する
4. 好きな順番で5施設を制覇する／ゴーカートで自己ベスト更新に挑む

戦闘・失敗・ゲームオーバー・落下は一切ありません。
小さなお子さまからゲーム初心者の方まで、安心して「遊園地にいる気分」を味わえます！

## 2. 操作方法

### 徒歩モード

| 操作 | アクション |
| ---- | ---------- |
| `W / A / S / D` | 移動（斜めでも加速しないよう正規化済み） |
| `マウス移動` | カメラオービット（上下は-55°〜+35°にクランプ） |
| `左クリック` | マウスキャプチャ開始 |
| `Esc` | マウスカーソル解放 |
| `Space` | ジャンプ（接地中のみ） |
| `Shift` | ダッシュ（歩行速度 5.0m/s × 1.5倍） |
| `E` | 乗り場で乗車リクエスト／乗車中に降車リクエスト |
| `R` | 乗車中：ゴーカートのみ最終チェックポイントに戻る |

HUD上部には常に `WASD MOVE MOUSE ORBIT SPACE JUMP SHIFT SPRINT E RIDE ESC RELEASE` と表示されるので、初めての方でも30秒で操作を覚えられます。

### ゴーカート専用モード

| 操作 | アクション |
| ---- | ---------- |
| `W` | アクセル |
| `S` | ブレーキ／バック |
| `A / D` | ハンドル（速度に応じた切れ味調整あり） |
| `Shift` | 強ブレーキ |
| `R` | 最終通過チェックポイントへ復帰（救済措置） |
| `E` | カートから降りる |

カウントダウン `GET READY — 3,2,1` の間は操作がロックされ、フェアなスタートが切れます。

## 3. 登場アトラクション全5種

すべてプリミティブだけで組み上げられ、色分けで遠くからでも一目で分かります。
近づくと `NOW VISITING:{施設名}` のロケーション表示と `E RIDE:{施設名}` のプロンプトが出ます。

### 3-1. 観覧車 Ferris Wheel（赤×黄）

- **場所：** 中央広場の北西 `[-14, 0, -7]`
- **構造：** 2本の脚＋ハブ＋10本のスポーク＋10個のキャビン
- **動き：** 0.22 rad/s でゆっくり1回転（約28.6秒で1周）
- **見どころ：** キャビンが常に水平を保つよう逆回転制御！乗車中は園内全体を見渡せます
- **乗降：** 乗車 `[0,0,1.8]` → 降車 `[0,0,2.9]`

のんびり回る姿を外から眺めるだけでも癒やされます。まずはこの赤い大輪を目指しましょう！

### 3-2. ジェットコースター Roller Coaster（紫×オレンジ）

- **場所：** 中央広場の北東 `[11, 0, -7]`
- **構造：** 高さ2〜5mの8点閉ループ軌道＋2本レール＋支柱＋駅ホーム
- **動き：** カート速度 3.4m/s で起伏のあるコースを自動周回
- **見どころ：** 線形補間で滑らかに走行。乗車中はカメラが振り回されないよう搭乗時の向きを維持する特別仕様で、酔いにくく景色に集中できます！

レールの起伏とカーブを間近で見ると「プリミティブだけでここまでできるの！？」と驚くはずです。

### 3-3. メリーゴーラウンド Carousel（ピンク×黄）

- **場所：** 中央 `[0, 0, 10]`（南寄りで一番アクセス良好）
- **構造：** 半径4mの土台＋中心ポール＋円錐キャノピー＋8頭のお馬さん（カプセル＋ポール交互カラー）
- **動き：** 0.45 rad/s で約14秒で1周
- **見どころ：** クルクル回るキャノピーとパステルカラーの行列は写真映え抜群！

お子さま連れ気分でほっこりしたい時にぴったりです。

### 3-4. フリーフォールタワー Free Fall Tower（青×黄）

- **場所：** 南西 `[-22, 0, 14]`、高さ24mの園内最高建造物
- **構造：** 4本タワー＋上部梁＋円形プラットフォーム＋ハーネス付きゴンドラ＋6個の点滅ランプ
- **シーケンス：** `乗車 → ハーネス → 上昇（5m/sで20mまで） → 静止（毎回ランダム2.5〜4.5秒！） → 落下（最大22m/s） → 制動 → 整定 → 自動降車`
- **見どころ：** 落下中の途中退出は不可！`HOLD ON...` → ランプ点滅 → `DROP!` の「間」が最高にドキドキします
- **HUD：** `ASCENDING / HOLD ON... / DROP! / SETTLING` と実況表示されます

本作随一のスリル担当。頂上からの眺めと一気に落ちる爽快感をぜひ体験してください！

### 3-5. ゴーカート Go-Kart Circuit（オレンジ×緑）

- **場所：** 南東 `[21, 0, 14]`、全長約70mのS字サーキット
- **コース：** 10点の閉ループ、幅3.6m、チェックポイント4箇所 `[2,4,6,8]`＋スタート／ゴール
- **ルール：** 3周タイムアタック！逆走・ショートカットは無効判定、衝突すると速度35%に減速
- **記録：** `LAP 1/3 TIME 0:12.34 BEST 0:45.67` とリアルタイム表示、`FINISH!` 後3秒で自動降車、ベストは `user://primitive_park_records.cfg` に自動保存
- **救済：** コースアウトしても `Rキー` で最終門に即復帰

唯一「自分で操縦できる」アトラクションです。最初は完走、次はベスト更新と、長く遊べる作りになっています！

## 4. パークの世界 — プリミティブへのこだわり

- **使用メッシュは4種のみ：** `BoxMesh / CylinderMesh / SphereMesh / CapsuleMesh` をコードで厳密監査。不正メッシュは起動時エラーになります
- **全施設を実行時生成：** `Main.tscn` は `Main＋Park＋Player＋HUD` の3ノードのみ。あとは `assets/data/park_config.json` 1ファイルの設定から `park_builder.gd` が自動生成します。色・位置・速度を変えたければJSONを書き換えるだけ！
- **園内導線：** 南門（幅8m）→ 南北67m・東西64mの十字路 → 中央広場（半径5.5m）→ 各施設へ黄色い小道が分岐。迷子になりません
- **境界壁：** 高さ2.2mの壁で全周を囲い、どこから見ても園外落下なし
- **自然と光：** 8本の木（茶色幹＋緑球冠）、芝生グリーン＋小道ベージュ＋壁ピンクのパステル配色、昼空プロシージャルスカイ＋暖色ディレクショナルライトで明るく優しい雰囲気
- **プレイヤーもプリミティブ：** 球頭＋円柱帽子＋カプセル胴体手足＋箱靴の赤帽くん。歩行時は腕を28°振ってトコトコ歩き、乗車時は脚58°のちょこんと座りポーズに変形します
- **カメラ配慮：** SpringArm3D（長さ4.5m）で壁貫通を防止、コースター乗車中のみ方位固定で酔い軽減

外部モデル・テクスチャ・音声はゼロ。JSONとGDScriptだけでこの賑わいを生み出しているのが最大の技術自慢です！

## 5. ゲームシステム（スコアなしの体験完遂型）

- **敵・アイテム・通貨・クエストなし。** 純粋に「歩く・見つける・乗る」を楽しむ設計です
- **進行管理：** `AVAILABLE → WAITING → RIDING → AVAILABLE` の RideProvider共通規格で5種を統一。`Eキー → 到着待ち → 1周 → 自動降車` の流れは全施設共通で覚えやすい！
- **ランドマーク通知：** 施設圏内に入ると2.5秒間 `NOW VISITING` 表示。再入場で再表示されます
- **記録要素はカートのみ：** `mm:ss.hh` 形式ベストタイム保存。起動時バリデーションで設定不備があれば即エラー終了し、不正記録は無視して安全に継続します
- **多言語・セーフエリア対応：** HUDは `tr()` 国際化＋画面サイズ追従＋カート表示0.1秒スロットルで軽快動作

クリア条件の明示はありませんが、「5施設すべてに乗車＋カート3周完走」が実質的なコンプリートです！

## 6. 本ゲームの面白さ — 5つのポイント ✨

### ① 小さな発見の連続が楽しい「ご褒美ループ」

72m四方に赤・紫・ピンク・青・オレンジの巨像が常に見えています。「あの塔は何だろう？」と近づくと看板が出て、さらに近づくと `E RIDE` が出る。この **遠景シルエット → 看板 → 搭乗** の3段階ご褒美が、探索をやめられなくさせます。道も一本道なので迷子ストレスゼロです！

### ② 待つこと自体が演出になる「生きた遊園地感」

何もしなくても観覧車・コースター・メリーゴーラウンドは回り続けています。`WAITING FOR...` と表示されて到着を待つ間、キャビンが水平を保ちながら回る様子や、コースターが起伏を駆ける姿をぼーっと眺める時間がとても心地よいです。動く景観が「今日も遊園地は元気だな」と感じさせてくれます！

### ③ 落差のドラマ「フリーフォールの“間”」

20mまでゆっくり上がった後、毎回ランダムな2.5〜4.5秒の静止＋ランプ点滅＋ `HOLD ON...` 表示で緊張が最高潮に。「いつ落ちるの！？」と身構えた瞬間に `DROP!` で最大22m/s落下！しかも途中退出不可なので逃げ場なし。この「待たされる怖さ」こそフリーフォールの醍醐味です。ぜひ音量を上げて（心の中で）叫びながらお楽しみください！

### ④ 自分で操る達成感「ゴーカート3周タイムアタック」

本作で唯一ハンドルを握れるアトラクションです。S字を抜け、チェック門を順番に通過し、壁にぶつかりながらも3周完走した時の達成感は格別！ベストタイムが自動保存されるので「あと0.5秒縮めたい…」ともう1周、もう1周とハマります。`Rキー救済` があるので初心者でも完走できます！

### ⑤ 失敗なし・軽快・かわいい「プリミティブの安心感」

敵に襲われない、落ちて落ち込まない、引っかかってイライラしない。境界壁と衝突設計の割り切りで、とにかくストレスフリーです。赤帽くんのトコトコ歩きとちょこんと座りを眺めているだけでも癒やされます。外部アセットゼロの手作り感が「自分でも作れそう！」という創作意欲まで刺激してくれる、優しくて元気をもらえるゲームです！

> 一言でいうと、**「眺めて癒やされ、乗ってドキドキし、走って燃える」三段構えの小さな幸せパーク** です！

## 7. 遊び方（実行方法）

### Godotエディタで遊ぶ（おすすめ）

1. Godot 4.6（4.6.2推奨）をインストールし、JoltPhysics3Dを有効化
2. `my-game/project.godot` をプロジェクトとして開く
3. メインシーン `res://scenes/Main.tscn` を `F5` または ▶ボタンで実行
4. スポーン地点 `[0,1.05,31]`（南門内側）からスタート！

キーバインドはコードで自動補完されるため、InputMapの事前設定は不要です。マウスキャプチャを使うため、実ウィンドウでのプレイがおすすめです。

### Webビルドで遊ぶ

- `export_presets.cfg` に `Web` プリセットを用意済み（出力先 `build/web/index.html`）
- `gl_compatibility` レンダラー＋スレッドオフのため、低スペックブラウザでも動作軽快です
- エクスポート後はブラウザで `index.html` を開くだけ！

## 8. 技術ハイライト（開発者向け）

- **完全データ駆動：** 世界・プレイヤー速度・施設色・タワー高さ・カート性能まで `park_config.json` に集約。起動時 `park_config.gd validate()` で200項目近く検証し、不備があれば即終了で安全に失敗します
- **RideProvider共通契約：** 3シグナル＋7メソッドで5種の乗り物を統一。`RideCoordinator` が重複接続防止つきで一元管理します
- **純粋計算の分離：** `movement_math / ride_math / kart_math` に切り出し、ヘッドレス321アサーション＋実画面QAで検証済み
- **位相ループ堅牢性：** 負値・多重ループ対応の `fmod` 正規化＋大刻みdelta到着検出で、フレーム落ちでも乗り過ごしません
- **イベント駆動HUD：** ポーリングなしのシグナル接続＋i18n（`assets/i18n/ui.csv`）＋セーフエリア対応
- **衝突の割り切り：** 固定物のみ衝突あり、動部品・装飾は衝突なしで引っかかり防止。カートのみCharacterBodyでバリアと衝突します
- **永続化の故障分離：** ベスト記録が書けなくてもゲームはそのまま続行します
